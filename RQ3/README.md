# RQ3: hand-shape features and joint measurements

This guide describes the RQ3 contribution. Installation, the input bundle and the shared baseline are covered in the main [README](../README.md). The project has three contributions: RQ1 targeted data collection, RQ2 detection recovery, RQ3 feature comparison.

## Question and main comparison

**Can explicit hand-shape categories and joint measurements supplement or replace Shin's landmark directions?**

| Block | Description | Inputs |
|---|---|---:|
| D | Normalized distances between image landmarks | 190 |
| S | Shin directions between image landmarks; not internal joint angles | 630 |
| E | Own categories: flexion, spreading, crossing, thumb shape and contact | 70 |
| J | Joint measurements from estimated world landmarks | 15 |

D is always present. S, E and J are independently included/omitted: **DS, D, DSE, DE, DSJ, DJ, DSEJ and DEJ**. The full representation has 905 inputs. Workbook-match scores are excluded.

Eight representations, two learners and five fixed folds produce 80 models. Only 60,251 accepted original single-hand detections are included. All variants share sources and test folds. The SVM DS baseline has 97.38815% macro-precision and 0.97386235 macro-F1.

A same-coordinate control derives J from Shin's image points to distinguish representation changes from coordinate-source changes. After training, features are shuffled across 13,000 fixed held-out images: 3,900 group interventions measure fitted-model dependence. Permutation does not refit the model; the eight training variants measure adding/removing information.

## Run

From the repository root, after installation and extracting both `rq3_inputs.zip` and `rq3_results.zip` as described in the main README:

```bash
python -m baseline verify-data
python -m baseline verify-results
python -m baseline check
python -m baseline verify
python -m RQ3 list
python -m RQ3 features --dry-run
python -m RQ3 features
python -m RQ3 coordinate_control
```

`features` checks inputs, trains both learners, permutes, exports, verifies and reports. Matching checkpoints are resumable. After the training run has finished, verify its saved models and results:

```bash
python -m RQ3 features --action verify
python -m RQ3 coordinate_control --action verify
```

Replay requires the inputs and fold models. [workflows.py](workflows.py) defines the public commands and output directories. The numerical implementations remain in [feature_factorial.py](../research/studies/feature_factorial.py) and [compare_direction_joint.py](../research/studies/compare_direction_joint.py), preserving the frozen source paths used by the core protocols.

## Findings

- Adding E to DS loses 22 correct SVM predictions.
- Adding world J gains 67; the same-image-coordinate control gains only four.
- Adding both E and J loses three.
- The small world-joint gain does not recur with LightGBM. Without S, the tested categories/joint measurements do not fully replace Shin directions.

These findings concern fixed profiles and this dataset selection. World and image coordinates differ. Folds are filename blocks, not verified people, and were inspected during development. Scores describe exploratory classification after accepted detection, not new-user or webcam accuracy.

Evidence (restored from the result archive or generated by the workflows): `results/feature_factorial_01/` and `results/direction_joint_01/`. Main files are `metrics.csv`, `paired_changes.csv`, `permutation*.csv` and `protocol.json`.

### Paired fold and letter diagnostics

The existing held-out predictions can be analysed without retraining:

```bash
python -m RQ3 diagnostics
python -m RQ3 diagnostics --action verify
```

The feature workflow also runs these diagnostics after verifying its predictions. Outputs are `fold_changes.csv`, `letter_changes.csv` and `summary.json` under `results/feature_diagnostics_01/`. Each comparison pairs the same source IDs, labels and folds, then independently checks corrected/new errors and precision/F1 differences against the saved scores. Ranges across folds are descriptive: folds share training data and filename groups are not verified participants, so the ranges are not confidence intervals or significance tests.

For SVM, DSJ corrects 143 DS errors and introduces 76: net 67 extra correct predictions, or 0.11 percentage points in accuracy. F1 improves in all five folds by 0.053-0.257 percentage points. Folds 2-3 account for 50 of the 67 net gains; M gains 31 and O loses seven. LightGBM DSJ loses 48 correct predictions overall. These contrasts describe the existing fixed predictions, with no new model fits.
