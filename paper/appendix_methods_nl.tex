\section{Data, representations and evaluation}\label{app:protocol}
This supplement supports RQ3. The shared numbering is RQ1 targeted/general augmentation, RQ2 detection recovery and RQ3 feature comparison. Executable RQ1/RQ2 contributions are still required.

\subsection{Images and fixed folds}
Of 78,000 A--Z Kaggle ASL Alphabet training images, 60,251 original images have one accepted hand (77.24\%). Failed detections are excluded. Supplied test images duplicate training sources and are not independent. Detector thresholds for the original feature cache were not retained; equal image counts do not establish equivalence with the separately recorded RQ2 settings.

Five fixed folds separate six blocks of consecutive file numbers, not verified participants or sessions. Every representation shares source IDs, labels and test folds. Each source receives one out-of-fold prediction. Folds were inspected during development; this is exploratory validation, not an untouched final test.

DSEJ has 905 inputs. E uses measured categories and a fixed column order, not the true letter. All eight representations use originals without augmentation or right normalization. D/S/E/J were recomputed on 390 sources; all 19 one-hot groups were checked across the full cache.

\subsection{Fitting and reporting}
Eight representations, two learners and five folds yield 80 fold models. SVM uses RBF, $C=10$, \texttt{gamma=scale} and balanced classes. LightGBM uses 100 trees, 31 leaves, learning rate 0.1, minimum 20 examples per leaf and seed 42. Only J is median-imputed and standardized using the training fold; D/S/E pass through unchanged. No representation-specific tuning is performed. Fixed model geometry limits the interpretation.

Pooled macro-precision and macro-F1 average A--Z equally; undefined letter scores are zero. Paired analysis counts corrected and newly introduced errors on the same sources. The separate image-coordinate J controls share sources, folds and profiles. D/S use image points; E/J use world points. Appendices D--F retain their own 835-input DSJ reference, distinct from DS with 820 inputs in the main comparison.

Code and evidence: \path{research/feature_study.py} and \path{results/feature_factorial_01/}. Protocols, source hashes, predictions and replay verify computation, not anatomy or linguistic ground truth.
